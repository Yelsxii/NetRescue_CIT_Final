# Historical material

These files are preserved for traceability. They are not the active Laravel
source or instructions for applying changes to the current installation.

| Directory | Contents |
| --- | --- |
| `issue-1/` | Original patch notes, manifest and the old `files/` source copies. The manifest describes that historical patch. |
| `early-qa/` | Earlier root-level QA reports. Use the current reports under `docs/` for the current procedures and evidence. |

The active models, controllers and services are in the root `app/` directory;
the active views are in `resources/views/`. Do not copy the archived patch over
them. Internal commands, relative references and screenshots in historical
notes describe the older project state and may no longer apply.
